Start a thread, pick Antigravity, and let the Google Antigravity CLI (`agy`) work in your repository from bb. The plugin drives `agy` in streaming JSON mode on the host machine and streams the agent's work into the bb timeline.

## What you get

- Full model catalog from `agy`, including Gemini 4 Argon, Gemini 3.8 Flash, Claude Opus 5.5, Claude Sonnet 5.5, and GPT-OSS 120B.
- Reasoning effort levels (`Low`, `Medium`, `High`) and composer plan mode.
- Live quota and usage tracking in the Provider Usage sidebar widget (`5h` and `7d` windows for Gemini, Gemini 4 Argon, and Claude/GPT).
- Antigravity skills from your home directory and project.

## Requirements

- Install the Google Antigravity CLI (`agy`) on the host machine (`~/.local/bin/agy` or on `PATH`).
- Sign in with `agy login` on that machine.
